# دوائي 💊 | صوّر دواءك واعرفه فوراً

تطبيق ويب عربي متجاوب مع الجوال (PWA):
- 📷 صوّر أي دواء ليتعرف عليه (OCR + قاعدة بيانات)
- 🔍 بحث بالاسم أو المادة الفعالة
- 🗓️ جدول أدويتك وأوقاتها مع حفظ دائم وتنبيهات

## التشغيل
افتح `index.html` مباشرة، أو انشره عبر GitHub Pages.

## النشر عبر Pages
Settings → Pages → Deploy from branch → main / root
